TransparentSkill: A Semantic Latent Skill Interface for Hierarchical Multi-Task Manipulation

Anonymous submission for RA-L

TransparentSkill learns a semantically aligned continuous latent skill interface from annotated expert demonstrations, enabling interpretable hierarchical control, cross-task skill reuse, and effective early learning on the MT10 multi-task manipulation benchmark. The same interface can be invoked on simple real-robot tasks with deployment-time stabilization.

Abstract

Multi-task manipulation requires shared high-level abstractions, but existing policies remain opaque at the chunk-planning level. We present TransparentSkill, which learns a semantically aligned continuous latent skill interface from annotated expert chunks, then uses this interface for hierarchical control at the same chunk-level temporal granularity. On the MT10 benchmark, the learned interface shows effective early learning under a limited interaction budget and reaches strong final performance after extended training. On three simple real-robot tasks, the interface remains executable and interpretable under deployment-time stabilization.

🤖 Real-Robot Feasibility & Stabilization

We evaluate whether the learned semantic skill interface can be invoked on hardware across three simple manipulation tasks: Lift banana, Close drawer, and Place banana into drawer. Each task is tested with three decoding variants:

  • Direct latent — execute the planner-predicted latent command directly.
  • Anchored + adapt (RL) — execute an anchored latent after limited hardware adaptation.
  • No-light anchored (RL) — additional qualitative low-light rollouts using the same RL-adapted policy. These clips are not used as a quantitative robustness benchmark; they are included only to illustrate qualitative execution under a common visual variation in the real-robot setup (room lights turned off).
